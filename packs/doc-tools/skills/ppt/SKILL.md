# PPT 生成 - 項目簡報製作

根據用戶需求，生成專業的 PPT 簡報文件。

## 核心原則

**本指令與其他指令不同：生成 PPT 前必須先向用戶提問，確認需求後才開始生成。**

## 執行步驟

1. **分析項目**
   - 讀取項目結構、核心功能、技術棧
   - 了解項目的定位與特色

2. **向用戶提問（必須）**
   - 在生成 PPT 之前，必須向用戶確認以下問題，不可跳過：

   | 問題 | 說明 |
   |------|------|
   | 用途場景 | 商談、內部報告、技術分享、投資人簡報？ |
   | 目標受眾 | 技術團隊、管理層、投資人、客戶？ |
   | 重點方向 | 技術架構、商業模式、創新點、市場分析？ |
   | 頁數範圍 | 建議 10-15 頁，用戶可調整 |
   | 風格偏好 | 深色商務風、淺色簡約風、科技風？ |
   | 特殊需求 | 是否有額外內容、特定頁面、語言偏好？ |

   - 可根據項目特性追加相關問題
   - 等待用戶回覆後才進入下一步

3. **規劃 PPT 大綱**
   - 根據用戶回覆，列出每頁的標題與要點
   - 以清單形式呈現給用戶確認
   - 用戶可對大綱進行增刪改

4. **等待用戶確認大綱**
   - 確認無誤後才進入生成階段
   - 用戶修改後需重新呈現修改後的大綱

5. **生成 PPT**
   - 生成或更新 `src/gen_ppt.py` 腳本
   - 使用 `python-pptx` 庫
   - 根據確認的風格選擇配色方案
   - 頁面內容依據確認的大綱撰寫
   - 輸出路徑預設為 `docs/` 目錄，檔名依用途命名

6. **執行生成**
   - 運行 `python src/gen_ppt.py` 生成 .pptx 文件
   - 告知用戶輸出路徑與總頁數

7. **後續調整**
   - 詢問用戶是否需要修改特定頁面
   - 支持局部修改後重新生成

## 技術規範

- 使用 `python-pptx` 生成
- 每頁設置背景色、標題、內容區塊
- 支持卡片式排版、表格、要點列表
- 字體大小：標題 36-40pt、副標題 18-24pt、正文 14-16pt
- 確保依賴已安裝：`pip install python-pptx`

## 參數

- `$ARGUMENTS`：用戶的簡要需求描述（可選），即使提供了描述，仍須進行提問確認流程
